# 真心（Zhenxin）

> 虚拟不代表冰冷，每一个ta都带着真心。

**v0.6.7 · 152 个测试 · AstrBot 4.29.1 实测 · MIT**

真心是给 AstrBot 用的长期记忆与上下文插件：不换模型，只决定每一轮让模型看到什么。

- **默认不检索**：平时只带 3 条极短线索，出现“你还记得…”才翻旧记忆；
- **写记忆零 LLM 调用**：规则蒸馏，不额外花 token；线索放请求末尾，保护缓存；
- **会遗忘**：记忆按重要度分入周期池 / 珍藏池 / 浅忆池，零价值信息进回收池；
- **颜色就是重要度**：记忆花园用 5 档融合色（淡灰→墨绿），重要度越高越深，点加深/减轻立刻变色；
- **学偏好，不模仿**：只记你明确说过的说话要求；联网学习只学“怎么说话/接话/共情”，
  不跟聊天话题走，论坛/聊天平台的常识先核对结果域名、再经模型甄别剔除广告才会入库；
- **对话分段默认开启**：长回复拆成几条短消息发出去；引用/图片/表情会跟着正确的那一条走，只改发送方式，不增加模型调用；
- **可选主动消息与插件体检**：默认关闭，不额外打扰、不额外花钱。

## 为什么要装它（和其他记忆插件的区别）

大多数记忆插件解决的是“记住”；真心解决的是“记得住，同时不烧钱、不失控”。
AstrBot 里常见的三种做法，代价大概是这样的：

| 常见做法 | 每轮成本 | 缓存 | 写入记忆 | 遗忘与可控性 |
| --- | --- | --- | --- | --- |
| 把历史/摘要塞进上下文 | 随对话线性增长 | 前缀每轮变化，命中差 | 无 | 只能手动清空 |
| 向量检索 / mem0 类 | 检索结果 + 抽取调用 | 检索段常进系统提示，破坏前缀 | 通常要额外 LLM | 靠分数阈值，不直观 |
| 自动压缩 / 总结插件 | 摘要 + 压缩调用 | 每轮改写系统提示，命中差 | LLM 摘要 | 越压越糊，原话会丢 |
| **真心** | **默认 3 条、约 300 字** | **稳定前缀 + 线索放请求末尾，缓存持续命中** | **规则蒸馏，0 LLM 调用** | **分池 + 保持度，点阵里可手动加深/减轻** |

### 最突出的三个亮点

1. **省钱是设计目标，不是副作用**：系统提示和最近窗口保持稳定，记忆只追加在请求末尾；
   记忆更新不会让整段前缀缓存失效。写记忆完全不调用模型。
2. **默认“不检索”**：平时只带 3 条长期线索；只有出现“你还记得…”“上次说的…”才翻旧记忆。
   既不会每轮把整个记忆库灌进上下文，也不会因为检索噪声答非所问。
3. **记忆看得见、摸得着**：记忆花园把记忆画成可缩放、可拖动的点阵；
   点一下加深、点一下减轻（连续减轻会降池）；四个池子和遗忘曲线在页面上直接可见。

### 什么时候不适合用它

- 已经在用会接管上下文的其他记忆/压缩插件：会互相打架；共存时把 `l3.host_context_mode` 设为 `off`。
- 完全不介意 token 成本，只想“把所有聊天记录都塞给模型”：那不需要真心。

## 安装

**方式一：AstrBot 插件市场**

面板 → 插件 → 安装插件 → 搜索「真心」。

**方式二：Release zip**

下载 `astrbot_plugin_zhenxin-0.6.7.zip` → 面板 → 插件 → 从文件安装。

**方式三：GitHub**

```bash
cd AstrBot/data/plugins
git clone https://github.com/xiaml666/astrbot_plugin_zhenxin.git
```

重启 AstrBot。要求 AstrBot `>=4.16,<5`；`TextPart.mark_as_temp()` 在 4.24+ 可用，低版本会自动把本轮提示并入 `req.prompt`。
